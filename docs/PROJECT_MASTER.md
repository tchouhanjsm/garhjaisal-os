# GarhJaisal-OS Project Master

## Vision

Build a lightweight Hotel Operations System for a 7--10 room heritage
hotel using Google Apps Script, Google Sheets, Drive, GitHub and Clasp.

## Tech Stack

-   Google Apps Script
-   Google Sheets
-   Google Drive
-   GitHub + Clasp
-   ESLint + Prettier + GitHub Actions

## Key Decisions

-   Review every feature from:
    1.  Hotel Owner
    2.  Senior Software Engineer
    3.  Product Lead / UX
-   Booking and Invoice remain separate.
-   Invoice uses Header + Line Items architecture.
-   PDF generation follows after billing model.
